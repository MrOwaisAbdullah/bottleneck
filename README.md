# Workflow Bottleneck Analyzer

An interactive visual diagnostic tool designed to help businesses and operational teams identify workflow bottlenecks, resource constraints, and throughput blockers.

## 🔍 Features
- **Constraint Identification**: Step-by-step diagnostic input to uncover hidden workflow delays.
- **Visual Feedback**: Clean UI displaying cycle times, handoff friction, and capacity limits.
- **Actionable Insights**: Recommendations on resolving process constraints based on Theory of Constraints (ToC).

## 🛠️ Tech Stack
- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3
